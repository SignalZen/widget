Hostile host page

This page sets serif fonts, red text, a yellow background, and a global * { box-sizing: content-box } reset. The SignalZen widget in the bottom-right loads via the standard install snippet and must ignore all of it — because it lives inside a Shadow DOM.

Install snippet

Step 1: Replace YOUR_APP_ID below (and in the script at the bottom of this file) with your App ID from the SignalZen console → Settings → Install.

Step 2 (production): Change e.src to "https://cdn.signalzen.com/signalzen.js".

<script type="text/javascript">
var _sz=_sz||{};
_sz.appId="YOUR_APP_ID";
(function(){var e=document.createElement("script");e.src="http://localhost:8081/signalzen.js";e.setAttribute("async","true");document.documentElement.firstChild.appendChild(e);var t=setInterval(function(){"undefined"!=typeof SignalZen&&(clearInterval(t),new SignalZen(_sz).load())},10)})();
</script>

The launcher appears once the session loads. All theming (colors, icon, shape, shadow) is configured in the SignalZen admin console and delivered via the session API.

Embedded in a div
